# Modelo de Regresión Lineal - Predicción de precios de vehículos 🚗

Este proyecto utiliza un dataset de Kaggle para predecir precios de automóviles mediante un modelo de regresión lineal.

## Tecnologías usadas
- Python
- Pandas, scikit-learn, matplotlib, seaborn
- Jupyter Notebook

## Dataset
[Vehicle dataset from Cardekho](https://www.kaggle.com/nehalbirla/vehicle-dataset-from-cardekho)

## Resultados
El modelo obtuvo un R² de 0.85, indicando buena precisión en la predicción.
